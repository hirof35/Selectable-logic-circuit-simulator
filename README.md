# 選択式論理回路シミュレーター

C++で実装されたコンソールベースの論理回路シミュレーターです。キーボードからの対話的な計算と、テキストファイル（CSV形式）を用いた一括計算に対応しています。

## 機能一覧

- **対応論理ゲート（全6種類）**
  - `AND`（論理積）
  - `OR`（論理和）
  - `NOT`（論理否定・1入力）
  - `NAND`（否定論理積）
  - `NOR`（否定論理和）
  - `XOR`（排他的論理和）
- **2つの計算モード**
  1. **キーボード入力モード**：演算種別と入力値を対話形式で指定して計算し、必要に応じて結果を `result.txt` に追記保存できます。
  2. **ファイル一括計算モード**：`input.txt` を読み込み、全行を一括計算して結果を `output.txt` に出力します。

## 動作環境・ビルド方法

- **言語**：C++（標準ライブラリのみを使用、C++11 以降推奨）

### コンパイル例（g++）

```bash
g++ -std=c++17 -Wall -Wextra -o logic_sim main.cpp
実行例
Bash
./logic_sim
使い方
プログラムを起動すると、以下のメニューが表示されます。

Plaintext
===== 選択式論理回路 メニュー =====
1. キーボードから入力して計算
2. ファイルから読み込んで計算
3. 終了
===================================
選択してください：
1. キーボードから入力して計算
メニューで 1 を選択します。

演算名（AND, OR, NOT, NAND, NOR, XOR ※大文字・小文字不問）を入力します。

入力A（0 または 1）を入力します。NOT 以外の演算では続けて入力B（0 または 1）を入力します。

計算結果が表示された後、y を入力すると実行ディレクトリ内の result.txt にCSV形式で追記保存されます。

result.txt の出力例：

Plaintext
AND,1,0,0
NOT,1,-,0
2. ファイルから読み込んで計算
実行ファイルと同じ階層に input.txt を配置した状態で、メニューから 2 を選択します。

空行および # で始まる行はコメントとして無視されます。

入力値（入力A・入力B）は 1、true、yes（大文字・小文字不問）を真（1）、それ以外を偽（0）として解釈します。

input.txt の書式例：

Plaintext
# 論理ゲートテストケース
AND,1,0
OR,1,1
NOT,1
NAND,1,1
NOR,0,0
XOR,1,0
計算結果はコンソールに表示されると同時に、output.txt に書き出されます。

output.txt の出力例：

Plaintext
演算,入力A,入力B,結果
AND,1,0,0
OR,1,1,1
NOT,1,-,0
NAND,1,1,0
NOR,0,0,1
XOR,1,0,1
クラス・関数構成
LogicGate：各論理ゲートの演算メソッド（andGate, orGate, notGate, nandGate, norGate, xorGate）および演算ディスパッチを行う calculate() を提供します。

strToBool()：文字列を bool 値へ変換するユーティリティ関数です。

manualCalculate()：対話入力による計算と result.txt への追記処理を担当します。

fileCalculate()：input.txt の読み込み、一括計算、および output.txt への出力を担当します。
